- **A page with two or more words linked to pages opens again.** In 0.21.0 such a page never finished loading. One linked phrase worked, and so did page chips and web links.
- **Typing in a long page is fast again.** Brain no longer re-reads the whole page on every key. It saves the page after you pause, and never more than a second after your last change. On a 5,000-line page, a keystroke takes about a tenth of the time it used to.
