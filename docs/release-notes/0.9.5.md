- Brain now installs with one command on a fresh Ubuntu or Debian server. It asks for a password and, if you have a domain, sets up HTTPS for you. Running the same command again updates Brain and keeps your notes and settings.
- The sharing card was rebuilt. It now reads as a short list of facts about the link: the address, who can open it, whether a password is needed, and when it stops working. The expiry no longer depends on the password, so a link can be set to end in a week without one.
