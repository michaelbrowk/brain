- The merged inbox no longer prints the account's name beside the time on every row. The section head and the open message say where a letter landed; the row is the sender and the subject.
- Archiving on an IMAP account that has no archive folder now works: the first time you archive there, Brain creates `Archive` (or `INBOX.Archive` where the server keeps every folder under the Inbox), subscribes to it and moves the thread. A server that refuses is answered as before; a connection that drops during the attempt is retried next time rather than remembered as a refusal. Trash and junk folders are never invented.
