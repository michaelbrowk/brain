- Writing a letter takes the whole window. The composer is a sheet of Brain's own paper over everything: the rest of the app recedes and goes quiet, the tab bar leaves on the phone, and one document remains: From, To with Cc and Bcc a word away, Subject, one line, the body. No field boxes. The actions sit on top, so Send is never under the keyboard. The sheet arrives in a quarter of a second with the rows following it in; Send keeps its size while it says "Sending"; a failed send is a sentence in the sheet's own slot and nothing moves. Reply and Forward use the same sheet, and one Escape closes one layer. Saving is silent; only a save that failed speaks.
