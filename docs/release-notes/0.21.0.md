- **A link pasted on its own line is a card you can write after.** Paste a web address on an empty line and you get its preview card with the caret on the line below. Enter, Backspace and the arrows behave on every browser and on the iPhone, where the next line used to jump above the card. Press Backspace at the start of the line after a card to edit its address. A click on the empty space under the last line puts the caret at the end.
- **Page links, files and images go in where the caret is.** `[[` in the middle of a sentence keeps the sentence whole, also in headings, lists and tables. Link to page over selected words links those words. After /image or /file you keep typing after it, and the image is no longer replaced by the next key.
- **Nothing you type is lost when you close the tab or switch apps.** Brain sends the last words even if an earlier save is still on its way, for pages of any size, and keeps retrying a save that failed until it lands.
- **Images in headings and table cells stay put.** A page that held one used to lose the heading or the cell when it opened. If a page ever opens with something Brain cannot show, it opens read-only and leaves the file alone.
- **Tables take a paste from a spreadsheet** and grow to fit it. Tab indents in a code block and adds a row at the end of a table, Enter starts a new line in a cell, and Escape leaves the editor.
- **Callouts and toggles start empty, and a toggle's title is yours to edit.** Brain remembers which toggles you folded.
- A page whose text began with a `---` block no longer loses that block when it is saved.
- An image at the start of a list item now shows inline. Typing a slash command in Russian filters the menu. Columns start in the left column.
- Security updates for the editor core, the web framework's image library and the agent connection.
