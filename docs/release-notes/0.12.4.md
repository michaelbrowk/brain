- A public page shows a child's live title. A page renamed after it was linked used to appear on a shared page under the name written the day the link was made ("Untitled" for a page named later); the public page now draws every page ref inside the shared subtree with the target's current title and icon, the way the editor does, and keeps the written label for anything outside the share. An editable share's visitor sees the same, and a visitor's save re-bakes those labels the way the owner's does.
- Sharing a parent folds a nested share into it. Opening Share on a page whose child already has a link used to stop at "resolve the existing grant first". The card now offers one action, "Share this page instead": the parent becomes the single link over the subtree, its settings come off the grants it absorbs (edit on if any had it; nothing carried over from an older revoked link), and the child's old address keeps working, opening inside the parent's link. A nested link that carries a password or a deadline is left alone until you lift the gate. Revoking the parent ends the old addresses too. The rules are written down in docs/sharing.md.
