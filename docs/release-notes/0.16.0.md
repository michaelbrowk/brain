- An IMAP account can send. The account form gains an "Outgoing (SMTP)" section: the server, a username that follows the incoming one, and Security with its port (465 with TLS, 587 with STARTTLS; nothing else reaches the wire). The outgoing server uses the same app password as the incoming one, and adding or changing it asks for that password again. Once it is saved, Reply, Reply all, Forward and New message appear for that account. The account card shows the outgoing server or says "Receive only", and offers to add or remove it. iCloud, Gmail, Fastmail, Outlook and Yahoo are filled in from the address; any other domain gets `smtp.<domain>` to correct.
- The mail service sends directly from the host when `BRAIN_MAIL_SMTP_DIRECT_ENABLED=1` is set in its environment: the same pinned-address, verified-TLS, authenticate-after-TLS path the relay used, without the relay. A Brain without the flag stays receive-only for IMAP accounts and says so in the form, with a one-press way to connect without an outgoing server. A saved outgoing server survives a password change while the flag is off.
