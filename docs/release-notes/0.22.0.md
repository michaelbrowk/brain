- **Links to the web, the way you expect them.** Paste an address over selected words and the words become the link. Select words and press ⌘⇧K, or Link in the toolbar, to add, change or remove a link. An address you type turns into a link once you type the space or press Enter after it. A Brain page URL pasted over words links them to that page and keeps the words.
- **Your Markdown stays as you wrote it.** Opening and saving a file you wrote by hand no longer rewrites its bullets, numbering, headings, rules, line breaks or tables. Only the lines you edit change.
- **A page you have open follows edits made elsewhere.** When another device or an agent changes the page, the change appears in place: your cursor stays where it was and your undo history is untouched. If you were typing at the same moment, nothing is overwritten. The page asks which version to keep: **Keep mine**, **Take theirs** or **Save a copy**. Whichever you pick, it keeps saving.
- **Writing on a phone.** While you type, a bar above the keyboard holds indent, outdent, task, undo, redo, the slash menu and a button that hides the keyboard. The line you are writing stays above the keyboard.
- **Typing in a long page is fast again.** Brain no longer re-reads the whole page on every key. It saves after you pause, and never more than a second after your last change.
- **A page with two or more words linked to pages opens again.** In 0.21.0 such a page never finished loading.
- **One unreachable mailbox no longer blocks updates.** Mail's health check reports it as degraded instead of failing, so a new release can install.
- Security update for the web framework.
