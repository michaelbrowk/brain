# Mail links, layouts and archiving

Buttons and links in HTML emails open again. Newsletters keep more of their formatting on phones, and forwarded messages include the text from HTML-only emails.

Done now distinguishes threads Brain archived from those that had already left the Inbox. Clearing Seen or Newsletters keeps new replies visible, even after a refresh.

Brain remembers where it moves IMAP messages so Undo can return them after a restart. Messages moved before this update may still need to be restored in your mail provider’s app.
