- Search in ⌘K now looks through mail and tasks as well as pages. Three groups in one list, Pages, Mail and Tasks, and the arrow keys walk through all of them. Enter on a letter opens it inside Mail; Enter on a task opens Tasks with the row in view.
- Mail search covers subjects, senders and previews across every account; message bodies stay out of the index. Each group shows its five best matches and a Show all row for the rest, and the cursor stays where the list grew.
- A module that is switched off has no group in search and sends no request.
- On the Mail and Tasks screens the palette's own commands sit under Mail actions and Tasks actions, so they never share a heading with results.
- Archive works on an IMAP account whose archive folder carries a localized name, such as Архив, Archiv or Archivo, on a server that does not mark the folder as the archive. A refusal the app remembers now lapses after ten minutes, so a folder made in another mail client is found without a restart.
- Search stays quiet about mail when Brain runs without its mail service: no failure row under every query.
