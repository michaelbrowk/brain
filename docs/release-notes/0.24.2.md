# Task menus and smoother scrolling

Long category and linked-page lists now scroll with a trackpad while editing a task. The task stays open, and the page behind it stays still.

Date pickers inside a task also scroll correctly when the available space is limited.

Repeat now matches the other task properties, and task rows show the familiar Brain hover background across the full clickable row.

Right-click a category to complete its open tasks or delete the category while keeping its tasks. Task rows also have a context menu for opening, completing and deleting a task. Completing a category offers one Undo for the tasks changed.

The Tasks sidebar marks the current list or category with bold text and a filled icon. Its background appears only on hover.
