- The Tasks column has a head, the way a note does. The list's name stands in the page-title register at the top of the column, with the day under it for Today ("Wednesday, 16 September"), and the list starts below it at the same height a note's body does. The title is the list switcher; the small pill in the band waits and materialises only once the title has scrolled out, the way the lone breadcrumb does. The column scrolls on its own now, which it never did, so its floating head and the blur at its top edge finally hold on a list longer than a window.
- Escape peels one layer at a time on a task row. With the When picker, the category picker, the repeat menu, the title editor or the capture row's picker open over an expanded row, one Escape closes that layer and leaves the row expanded with the focus back on its trigger; the next Escape folds the row. A press that dismisses a layer belongs to that layer, so a tap on the capture row's chip no longer folds the row under it.
- What an agent did shows in the bell. Every mutation an agent performs through MCP is a row in the notification centre: "Claude sent a message", "Claude created a task", "Claude saved an attachment to Meeting notes", "Claude wrote a page". Bursts of the same action fold into one row with a count, a read mark on a thread says nothing, reads and the Notion import write no rows, and nothing is pushed to a phone. Page writes are logged in Settings › Connections now as well.
- An outgoing message can carry 8 MiB of files, up from 5. The outbox holds the finished message as bytes rather than inside its JSON, the queue reads one message at a time, and the Gmail request body is written rather than stringified, so the memory contract holds at the new figure with room to spare (measured end to end, 154 MiB against a 192 MiB limit with twenty messages queued). The mail service's outbox moves to schema 3 on its first start; the migration is one way, and an unreadable legacy row costs that row and never the account. Ten MiB was measured too and does not fit under the limit, so it is not the figure.
- A send that failed after the outbox had taken it is answered as taken. A throw in the bookkeeping after a commit used to read as "sending is unavailable, try again" over a message already on disk; it is logged and dropped instead. One outbound message is in memory at a time on every lane, the draft one included.
- `get_mail_send_status` writes the Sent mark against the account the operation lives in, and refuses a caller naming a different one. A size refusal names both figures to the agent.
- `1. [ ] a` from a paste, an import or a loaded note is a bullet task now. The editor never holds a task item under an ordered list, so a note that arrived with one no longer answers "This note could not be read" to every `+ Task`. Opening such a note writes it once, in the fixed form.
- Smaller: the activity log's byte cap is exact on a torn tail; the modules the SMTP bundle inlines are one list shared by both builds and pinned against the projector; the release carries the outbox memory probe so the same measurement can be taken on the server.
