- A stranger can no longer lock you out of your own Brain. The sign-in limiter used to be one bucket for the whole world: five wrong passwords a minute from anyone, and the door stayed shut for everyone, you included. A browser that has signed in once now carries a small anonymous cookie (thirty-two random bytes and a signature, nothing about you, one year) and gets a bucket of its own; the shared bucket is still there for a browser that has never been in, and a browser whose own bucket is spent falls back to it rather than doing worse. A login request that arrives from another site is refused before it costs a password comparison. The password gate on a shared link keys the same way for a reader who is signed in; for a stranger it is still one bucket per link, and the notes say so plainly.
- The MCP bearer is compared as a fixed-width digest, so a wrong-length token is refused by the same comparison as a wrong one.
- The example nginx config answers a limited request with 429 instead of 503, gives the login and the MCP endpoint their own per-visitor buckets, and shows how to keep the app-frame token out of the access log. Both systemd units refuse new namespaces.
- An app page fills the window. The frame used to sit at its 420-pixel floor with empty paper under it, so an app's bottom button was cut in half on a tall screen; it now takes what the head leaves, on the phone above the tab bar, and shows a quiet in-progress fill while its address is minted and its document loads instead of a white block. A shared page names Brain in its link card.
- Small things: the stop-sharing dialog says its sentence once, the Modules description ends with a full stop, and the tool table lists the three app-page tools.
