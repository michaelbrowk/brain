# Task context for connected assistants

Connected assistants can now read and edit a task's notes, link Brain pages for context, and manage categories with emoji. These details use the same saved data as the Tasks interface. If the notes have changed since an assistant read them, Brain asks it to read the latest version before saving, preserving your newer edits.

The task tools also support All tasks. Planning, deadlines, repeating schedules and overdue tasks keep the same behavior, and tasks promoted from a page remain connected to their original checkbox.
