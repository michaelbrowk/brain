# Tasks, with room to think

Tasks now has a focused sidebar for Inbox, Today, Upcoming, all tasks and your categories. Larger category headings, page-style emoji and quieter task rows make a long list easier to scan. Overdue tasks stay visible, and completed work stays out of the way until you open it.

Open a task anywhere on its row to edit it in a popup. Its title is the heading, with notes, planning, deadlines and repeating schedules together. Create a category directly from the category picker, or link several Brain pages to keep the relevant context close. Categories and page links are saved with your notes and travel with exports.

On mobile, switch lists from the same compact menu pattern used by Mail and add tasks with the floating button. Search remains in Brain's global navigation.

This release also tightens connected-app consent and mini-app isolation, restores missing attachments when restoring a page version, and preserves Markdown text when importing page links. Installation recovery, automated checks and runtime dependencies have been updated.
