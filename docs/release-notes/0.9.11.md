- On a phone, the Send button in a new message no longer sits under the bar at the bottom of the screen. Everything else in the sheet moved up with it, so the draft and the discard control are reachable again.
- Keyboard hints now name the key you actually press. A Mac still reads ⌘K; Windows and Linux read Ctrl+K, which is what worked there all along.
- Installing over SSH tells you what it needs. Passing only a password used to stop with a message naming two settings, one of which you had already given. It now names the one that is missing and says that an empty BRAIN_DOMAIN= means you want to keep Brain on that machine.
- A page you capture from the box on the home screen gets an ordinary address, so a link you send no longer carries the word quickcapture in it. Pages you already made keep their links.
