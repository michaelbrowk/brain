- Anyone with the link can now edit a shared page, if you turn it on. They can change the text and upload images. They cannot delete, move or rename anything, and they never see the rest of your notes. Each person is asked for a name once, and it shows in the page's history beside what they changed.
- Turning editing on or off signs everyone out of the link, the same as changing the password or the expiry. Brain says so when it happens.
- Images in a shared page now have to live in Brain. One loaded from another site will not show to a visitor. That is what stops a person you shared with from putting a picture on the page that reports back every time someone opens it.
- A shared page lists its subpages again on installs with no public address set. That list had been missing for every share, read-only ones included.
