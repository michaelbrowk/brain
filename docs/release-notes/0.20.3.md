- **Done on a section no longer holds up the mail screen.** The rows leave at once and Undo shows its countdown from the press. Nothing is sent while you can still undo, so Undo is instant. When the countdown ends the letters are archived in the background, and every other mail action keeps working meanwhile. A reply that arrives in that time stays in the Inbox, unread, and the message says so.
- **IMAP accounts learn who you write to from your Sent folder.** People you answered from another mail app count as known, so their next first letter skips New senders.
- **Brain files mail only into folders your mail server names.** Archive, Trash, Junk and Sent come from what the server says about its folders, or from a known folder name at the top level. Brain no longer guesses from a name deeper down, so nothing is moved into a project folder that happens to be called Archive. Folder names in other languages are recognised.
- **Search tells you when it could not reach a mailbox, and catches up by itself.** The line names the mailbox that is still syncing, and clears on its own once the sync finishes. The letter under your cursor stays put while results update.
- **Search keeps a page that has the word in its body.** Search no longer runs out of matches on a page's dates and loses the page. It never shows a shared page's password hash as a match.
- **Home's mail block updates when mail arrives**, instead of on its own timer.
- **Menus show the keyboard's ring and never the mouse's.** The Mail and Tasks list menus ring the row you reach with the arrow keys and drop the ring as soon as the mouse moves.
- Pressing `u` right after a letter opens marks it unread, as it should.
- A letter whose content took a moment longer to prepare no longer ends in "couldn't load".
- Security updates for the web framework and the mail address parser.
