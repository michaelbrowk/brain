- Attachments open inside Brain. Pictures in a letter show as tiles, and a click opens them full-window: the arrow keys or a swipe move between the letter's pictures and PDFs, Download is one click, Esc closes.
- PDFs open in the same viewer, page by page, without leaving the app. Pages are drawn as pictures, so links, forms and scripts inside a PDF do nothing. A password-protected or broken file says so and offers Download.
- Pictures that a letter already shows in its text, such as the logos in a signature, no longer appear a second time in the attachment list.
- Previews share the letter's download queue, so a letter full of photos loads them one after another instead of refusing some, and the pictures in the letter's text always come first.
