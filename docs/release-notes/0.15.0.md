- The sign-in screen and the password gate on a shared link were rebuilt. Both are one drawing in Brain's own paper: the mark, one sentence, a field with a show-and-hide glyph, one button, the version quietly under the card. A wrong password is a sentence in the field's own slot ("That password did not match.") and nothing on the screen moves when it arrives; the button never travels under the hand that pressed it. Busy reads as busy, with a turning glyph beside the word rather than a dimmed button. The visitor's name dialog on an editable link speaks the same sentences. The gate still says nothing about the page behind it, on purpose.
- An attachment is named by its content. Save the same picture twice, from a paste, a drop, a visitor's upload or an agent saving it out of a message, and you get one file and one address; the second save writes nothing and commits nothing. The agent's `save_mail_attachment` is honestly repeatable now: two saves append one line. Files with the older random names keep working.
- A click beside a page chip puts the caret on a line that can take your next word. The blank paper to the right of a page reference used to park the caret inside the chip and swallow every keystroke; the caret now lands on the nearest line that takes keys, an empty one first, never a heading or a code block. The July complaint about `/` after making a subpage is pinned by a browser test and no longer reproduces.
- A task made by an agent no longer vanishes from Tasks until the next event: a list request that was in flight when you ticked a row is asked again, and your tick keeps its row. A task record answers with its author. Reminders survive a mail burst: the notification centre bounds each kind on its own.
- MCP works on a home network. `BRAIN_PUBLIC_ORIGIN` may be plain `http://` on a loopback, private or link-local address, or a `.local` / `.lan` / `.home.arpa` / `.internal` name; the login and share cookies follow the same rule so such an install can sign in; one line in the log says the tokens travel unencrypted there. Everything else stays https-only, the Gmail connection included, because Google accepts nothing else.
- The MCP endpoint measures before it allocates: a request body is bounded at 16 MiB, an app build's entry and assets are measured on what was sent before anything is decoded, and a client that hangs up mid-call still tears its session down. `pnpm audit --prod` runs on every push and pull request, so a critical advisory in a dependency reddens the build instead of waiting for a habit.
- The Spanish trainer learned three things: the two scripts a word and its translation are told apart by are a setting in its head (a Spanish-and-English notebook works now), the pages it reads are cached for the frame's life so a reload after one card does not re-read them all, and a card whose word left the deck leaves the screen.
