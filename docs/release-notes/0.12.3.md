- The static MCP token's client has a name. Rows in the bell and lines in Settings › Connections used to say "Legacy token"; `MCP_TOKEN_NAME` names that client (default "API token"), so an agent on the static token reads as "Claude created a page". Lines already written keep their word. The credential's own label in Connections is "Static token".
- A common word no longer sinks the search. The whole query runs first as a phrase, then each word; a run stops after its first 300 matches and answers what it read instead of refusing the search, so "Урок 15 сентября" finds the lesson note rather than failing on "15". A ripgrep failure is answered to an agent as `search_backend`, with ripgrep's own words kept in the server log.
