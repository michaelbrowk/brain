- Mail search indexes the whole mailbox in the background. It used to index 500 letters each time someone searched, so a large account answered from a fraction of its mail until you had searched a dozen times. Now each sync pass adds a batch until the index is complete, and a mailbox of several thousand letters is fully searchable within minutes of connecting or resyncing.
- While that first build runs, search says "Older mail is still being indexed" instead of "Mail index is still building".
