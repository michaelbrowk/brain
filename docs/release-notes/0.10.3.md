- The first sticker on a note never reached the server. Adding a sticker to a note that had none answered "Stickers changed elsewhere. Your draft is still safe.", and the sticker lived only in that browser: it looked saved because the page kept showing your draft, and every reopen raised the toast again. The server compared "no stickers yet" with "an empty list of stickers" and called that a conflict. They are one state now. A sticker you added this way is still in your browser's draft and saves on the next open.
- The 0.10.2 release never reached anyone: its build shipped without one of jsdom's helpers, every page answered 500 in the smoke test, and it was not published. pnpm keeps jsdom's dependencies as symlinks, and the release copier raced them, so some builds carried the files and some carried a dangling link, with timing deciding which one you got. The copier now sees only real directories, and the smoke test checks every one of jsdom's dependencies against jsdom's own manifest instead of a list of four kept by hand.
